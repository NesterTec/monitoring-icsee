Se na VPS o container tiver GO2RTC_PUBLIC_URL=/rtc, o iframe pede https://www.nestertec.com.br/rtc/... e cai no 404 do store (“Página não encontrada”), não no go2rtc. 

docker exec icsee-nvr printenv GO2RTC_PUBLIC_URL

Sync dos streams

  1. Cadastro/edição de câmera → go2rtc_sync.sync_go2rtc.
  2. Gera cam_{id} (sub) e cam_{id}_hd (main) com um producer ffmpeg cada.
  3. POST /api/restart no go2rtc.
