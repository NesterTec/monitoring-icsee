O que o monitor faz

  1. Periodicamente testa TCP no host:rtsp_port de cada câmera habilitada.
  2. Sucesso → reachability_status=ok, zera fail_count, atualiza last_seen_at.
  3. Falha → incrementa fail_count; após o limiar → lost + entrada em Logs.
  4. UI de Logs mostra os eventos recentes (sem modal/sino).
Armadilhas
  • App ICSEE no celular (nuvem) ≠ RTSP na LAN.
  • Dois IPs com o mesmo MAC podem ser a mesma câmera (alias) — não assumir rediscovery.
  • Scan na VPS só encontra hosts se o WireGuard + MASQUERADE estiverem corretos.
