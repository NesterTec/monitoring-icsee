Checklist operacional

  1. VPS: wg show com handshake recente; peer casa com AllowedIPs incluindo a LAN.
  2. Casa: ping 10.10.10.1; ip_forward=1.
  3. MASQUERADE na iface LAN ativa (Wi‑Fi wlx… ou cabo enp2s0) — se mudar a rede, atualize o PostUp.
  4. VPS: nc -vz <ip-cam> 554.
  5. Container: GO2RTC_PUBLIC_URL=/adm/house/monitor/rtc.
  6. Nginx store reload após alterar o snippet.
Recarregar WG em casa 
sudo cp ~/.config/icsee-wg0-home.conf /etc/wireguard/wg0.conf
sudo wg-quick down wg0
sudo wg-quick up wg0
