# ICSEE NVR MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Dockerized DVR: admin login, ICSEE camera CRUD with device credentials, go2rtc live view, continuous MP4 recording with configurable disk quota (oldest-first ring buffer).

**Architecture:** FastAPI app + SQLite owns auth, cameras, settings, and recording metadata; it generates go2rtc stream config and supervises per-camera FFmpeg recorders writing ~5-minute MP4 segments under a configurable storage path.

**Tech Stack:** Python 3.12+, FastAPI, Jinja2 (server-rendered UI), SQLAlchemy 2 + SQLite, argon2-cffi, cryptography (Fernet), httpx, pytest, Docker Compose, existing `alexxit/go2rtc`, FFmpeg.

## Global Constraints

- Project root: `/home/nestertec/Documentos/projects/icsee`
- Spec: `docs/superpowers/specs/2026-11-01-nvr-mvp-design.md`
- Admin email seed: `ivanrank@yahoo.com.br` (password from env `ADMIN_PASSWORD`, never commit plaintext)
- Default recordings path: `recordings/` under project; changeable in settings
- Recording: continuous 24/7 MP4 segments ~5 minutes; H.264 preferred for playback
- Quota: user-defined GB; delete oldest segments when over quota or disk reserve breached (~2 GB free minimum)
- MVP excludes: ngrok, PTZ, two-way audio, motion detection, multi-user
- Keep existing go2rtc container; app updates its config file or mounts a generated one
- TDD: write failing test → implement → pass → commit (init git in Task 1 if missing)
- Do not commit `.env` secrets

```yaml
    environment:

```
